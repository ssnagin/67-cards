## Shared interface reserve

The remaining files cover navigation arrows and chevrons, home and menu, visibility, filtering and sorting, contextual menus, information and warnings, upload and download, authentication, links, common circular actions, time and calendar, and user management.

Only files under `icons/outline/` are used. Filled variants were intentionally removed to keep one visual language and reduce repository size.
