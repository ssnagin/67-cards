# Карточки разработки 67 cards

Дата подготовки: 2 ноября 2026 года. Все карточки — запланированные работы, а не подтверждение реализации.
Структурированная версия: [tasks.json](tasks.json). Обзор: [PLAN.md](PLAN.md). Проверки требований: [REQUIREMENTS.md](REQUIREMENTS.md).
## Правила работы

Один ответственный и второй участник как проверяющий; конкретные люди назначаются перед взятием задачи. Поля исполнителя, проверки, кода и доказательств пока не заполнены. Не более одной основной задачи на человека одновременно. Оценки включают проверки. Подзадачи входят в оценку родителя и не суммируются повторно.
Общий критерий завершения: реальное поведение вместо заглушек; серверные права; необходимые проверки; обновлённая документация; проверка напарником; явный список непроведённых проверок и ограничений. Статус готовности не устанавливается только на основании этого описания.
## Перенос в YouGile

Назначение: существующий ToDo внутри «ИС». Доска и колонка ещё не идентифицированы: MCP URL не является их ID. В этой сессии нет подключённых инструментов YouGile; каталог подключений не вернул YouGile. Перед записью получить авторизованное подключение, прочитать доступную структуру и существующие задачи, однозначно определить проект/доску/колонку. При нескольких совпадениях запросить выбор.
Сопоставлять по точному префиксу [67C-XX] внутри подтверждённой целевой области. Если задача уже существует — не дублировать и не перезаписывать чужие изменения автоматически; сверить и внести только согласованное. Создавать последовательно или небольшими порциями, записывать возвращённые task ID в tasks.json и подтверждать содержимое чтением. При сбое продолжать с неподтверждённых ID. Существующие назначения, сроки, метки и колонки не менять без основания. Не создавать отсутствующую доску или колонку автоматически.
Создавать задачу с заголовком из разделов ниже, остальное содержимое использовать как описание. Если YouGile поддерживает отдельные поля зависимостей/оценок — заполнить их; иначе сохранить значения в описании. Не назначать всех задачам конечный срок 31 декабря: использовать контрольные точки плана без фиктивной точности.
