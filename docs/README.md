# Документация 67 Cards

## Требования

- `stage_1/ИС_курсовая_требования_Снагин_Станислав_Степанов_Илья_2026.pdf` — экспортированная версия описания проекта, функциональных и нефункциональных требований и архитектурных схем.
- `stage_1/ИС_курсовая_требования_Снагин_Станислав_Степанов_Илья_2026.odt` — редактируемый источник требований с комментариями участников.

При расхождении основной формальной версией считается PDF, а комментарии ODT используются как контекст до отдельного согласования.

## Дизайн

- [`design/DESIGN.md`](design/DESIGN.md) — состав FigCraft-файлов, карта экранов и состояний, требования к дизайн-системе, прототипам, адаптивности и передаче макетов в разработку.
- `design/99_Drafts_and_Archive.figcraft` — исследования и неутверждённые визуальные направления. Страница `Moodboard` содержит референсы владельца, а страница `01 — Web style / Dark Neon Editorial` — прикладной web style guide, собранный по этому мудборду: foundations, компоненты, desktop-пример и mobile live-сценарий. Ранее подготовленные Ink & Signal, Grid Play и Culture Club сохранены только как отклонённый архив.

## Зафиксированные вопросы

В дизайн-брифе перечислены продуктовые и технические неоднозначности, которые нужно закрыть до финализации макетов. Среди них: значение «главного экрана» для лидерборда, правила размещения «Рынка прогнозов», модель общего экрана, точные правила случайных механик, права совместного доступа и противоречие между Nuxt SSR и размещением на GitHub Pages.
